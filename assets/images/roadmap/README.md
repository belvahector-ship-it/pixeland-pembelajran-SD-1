# Roadmap Mascot Assets

- `robot-run.png` — robot berlari ke checkpoint berikutnya.
- `robot-fall.png` — pose jatuh ringan saat jawaban salah.
- `robot-retry.png` — robot muncul lagi dari lubang untuk pesan “Coba lagi”.
- `robot-celebrate.png` — selebrasi saat jawaban benar atau mencapai checkpoint.
- `roadmap-school-world.png` — latar peta lebar bertema sekolah, taman bermain, dan perpustakaan dengan jalur berliku.

Ilustrasi `../adventure-world.png` menjadi acuan gaya. Titik bernomor dan progres robot dibuat responsif di antarmuka agar jumlah checkpoint mengikuti total soal tiap mapel.
